# Release v0.8.0

## Changelog
- **Vitamins & Rare Candy**: Pokémon have a new Training tab where each core attribute (Strength/Dexterity/Vitality/Special/Insight) can be set to Vitamin or Rare Candy, granting +1 to its current value (never exceeding its max). Rare Candy is a strict upgrade over Vitamin - it also raises the attribute's max by 1. HP and Willpower have their own checkboxes that raise their max the same way. Attribute dots show Vitamin/Rare Candy increases in yellow, distinct from other bonus sources like Custom Effects (blue) (#132).
- **Training Points (TP) Actions**: the new Training tab also holds four TP-spending actions for Pokémon - **Rank Up** (advance to the next rank and allocate its points), **Retrain** (reset Attributes/Skills to reallocate at the current rank), **Learn Move** (pick a learnable move, choosing one to forget if already at capacity), and **Overrank** (learn a move from a rank above current - requires a combined Happiness + Loyalty of at least 7; learning a new Overranked move automatically forgets the previous one). Every action's dialog has a "Don't consume TP" checkbox for free adjustments, and posts a chat message stating how much TP was actually spent.
- **Evolution Stage**: Pokémon now track an Evolution Stage (First/Second/Final), populated from compendium data and editable per-actor from Actor Settings, which sets the TP cost of Learn Move and Overrank.
- **Custom Effect/Held Item/Ability Rules Overhaul**: rules now use a guided picker instead of a free-text path - **Attribute Override** picks from a fixed list (Attributes, Social, Skills, Derived stats, HP/Will max, Accuracy) to Add or Replace; **Type Override** (new) replaces one of a Pokémon's Type slots, for Soak/Terastallize-style effects, and locks that Type selector on the sheet while active; **Damage Pool Bonus** (new) adds dice to a move's damage roll, scoped to all moves, a specific Type, or a Category. Existing rules keep working unchanged.
- **Retired the old star-based Vitamin Tracker**: the header/attribute star indicators and the "Enable Vitamin Tracker" setting are gone now that the mechanical Vitamin/Rare Candy system replaces them - the Training tab is no longer hidden behind that setting either, it's always available for Pokémon. The old A/B Vitamin fields are kept for reference in the Actor Settings dialog (gear icon), which was also compacted (fields sit beside their labels now, with proper scrolling). In Edit mode, the small badge next to a boosted/reduced attribute now shows the actual +/- change instead of the total, styled to match the value circles beside it.
- **Matchup Modifier rule kind**: Custom Effect/Held Item/Ability rules can now grant Weakness, Resistance, or Immunity to a specific attacking type, or cancel an existing Immunity (a single type, or all of them at once) - without changing the Pokémon's actual type. Grants stack additively with the Pokémon's natural type matchups; damage rolls, clashes, the Attributes-tab matchup display, and the `pokemonMatchup()` macro API all reflect it consistently. Custom Effect items' Rules tab was also fixed to show the full guided rule-kind picker (Attribute/Type Override, Damage Pool Bonus, Matchup Modifier) - it had been stuck on the old free-text editor since the original rules overhaul.
- **Move Effects compendium**: a new "Move Effects (Custom)" compendium ships 17 ready-made Custom Effect items covering common move text effects with no mechanical backing before now (Soak's type change, Thousand Arrows removing Ground immunity, Victory Dance's damage bonus, and more) - drag one onto an actor and enable it instead of hand-building the rules yourself.
- **Evolve a Pokémon into a different species**: a new **Evolve** action (Training tab, in the section now labeled "Training Session" - or click a listed option in the Biography tab's Evolutions fieldset) lets you pick any Pokémon from any installed compendium and compares base stats side by side before applying. Confirming syncs the target's Attributes, Types, HP/Will, and species data; keeps every move already learned while replacing the rest of the movepool (skipping anything you already know by name); swaps Abilities; and resets Rank to none, immediately reopening Advancement for a free, full-pool point reallocation. Optional toggles update the portrait/token art and change Nature. The Evolutions list itself is now directly editable too - a "+" next to the Biography tab's Evolutions header opens a row editor instead of that list only ever being set by the data pipeline.
- **Pokédex Red alternate actor sheet**: Pokémon actors can now pick a second, from-scratch sheet skin - modeled after the games' Pokédex UI - as an alternative to the classic layout, from Foundry's own sheet-picker (the icon next to the sheet window's title). Every tab (Attributes, Moves, Items, Effects, Biography, Training) and every action/button from the classic sheet is present and functional. Purely additive - the classic sheet is untouched and stays the default.
- **Bugs & Fixes**: an in-combat Plus/Minus stat change on an attribute already boosted by a Vitamin (or any other prior bonus) could overwrite that bonus instead of stacking with it. The "Reworking" macro (Macros compendium) now resets a Pokémon's Rank, Skills, base stats, typing, and full species data to match its current compendium entry (previously only 5 attributes synced), no longer leaves a broken Active Ability selection behind, and asks for confirmation before wiping learned moves. The release build's zip was also silently missing both hand-authored compendiums (Macros and the new Move Effects) entirely - now included. The Skills tab's edit-mode max could get permanently stuck showing the wrong number, since it read a frozen persisted value instead of the live Rank-derived one - affected every Pokémon actor, not just newly Evolved/Reworked ones, now fixed. The actor sheet's default window height was increased to 650px. Vitamin/Rare Candy (and Custom Effect/Ability/Held Item rule, and ailment) bonuses to Strength/Dexterity/Vitality/Special/Insight weren't reaching HP max, Will max, Defense, Special Defense, Clash Physical/Special, Initiative, or Evade - only the attribute's own displayed value updated immediately, leaving those derived stats stale until an unrelated re-render happened to trigger. Actor Settings' Will Bonus field never actually saved - the schema field it needed was referenced everywhere except its own definition, so Foundry silently dropped the value on update.

## Notes
Please ensure you backup your existing module folder before updating.
This system remains compatible with Foundry V13, but V13 support is expected to end in an upcoming release.
